Native macOS screen zoom

Hold Right Ctrl and scroll the mouse wheel to zoom in or out. This is configured in System Settings → Accessibility → Zoom: enable “Use scroll gesture with modifier keys to zoom”, choose Control, and use Full Screen zoom. macOS selects Control without distinguishing left from right; Right Ctrl is your preferred key.

The scroll-to-zoom toggle and Control modifier values were read from this Mac on 30 September 2026 and are saved in preferences/macos.json. ./setup install (unless --skip-preferences) or ./setup defaults applies them with per-key backups. For the installed macos-defaults tool, preview with macos-defaults --dry-run apply macos-defaults/zoom.yaml and apply with macos-defaults apply macos-defaults/zoom.yaml; that direct tool command does not create the setup backup. Log out and back in if needed, then verify Right Ctrl + wheel and Full Screen style. Apple’s Zoom settings reference.

02 / COMMON TASKS

Everyday workflows

Start with a task, then reach for the tool you already configured.

Start coding

Press Hyper I for VS Code. Use ⌘ E to find a file, ⌘ ↑ / ⌘ ↓ to jump between code blocks, and ⇧ ⌘ Backspace to return to the last edit.

In a terminal: pp → j project-name → code . → prd. Use rs when you need to choose a package script.

Put two things side by side

Focus one window and press ⌃ ⌥ ←. Focus the other and press ⌃ ⌥ →. Move a window between displays with ⌃ ⌥ ⌘ ← / ⌃ ⌥ ⌘ →.

⌃ ⌥ Return maximizes the current window. These are Raycast commands.

Work with text

⌃ V opens clipboard history. ⌃ O recognizes text from the screen. ⌃ ⌃ looks up a word. Hyper O runs Improve Writing through the Ollama AI extension.

Your separate “Fix Spelling and Grammar” script reads the clipboard, calls local Ollama on port 11434 with model phi3, and copies the result back. It has no verified global hotkey.

Browse and capture

Hyper B opens Chrome; Hyper N opens Obsidian. Your saved Vimium convention is f to click a link and ⇧ F to open it in a new tab. This comes from your setup notes, not a live browser export.

For a selected area, ⌃ ⌘ ⇧ 4 copies to the clipboard; ⌘ ⇧ 4 saves a file in /tmp. These are your native macOS shortcuts. Use Zappy for images, GIFs and quick videos; use QuickTime Player for better-quality video.

Restore your editor on another Mac

  1. Open VS Code’s Profiles menu and choose Import Profile.
  2. Import the matching .code-profile file from editors/vscode/. It contains current settings, shortcuts, snippets and extension IDs.
  3. Select Cursor Default for your usual coding workflow. Your live settings are untouched. Core setup leaves VS Code alone; only the optional vscode link profile replaces editor files. Profile IDs are resolved by name.

Open Keyboard Shortcuts in VS Code to resolve an extension command that no longer exists. The imported Cursor-specific Agent key is preserved but may not do anything in VS Code.

Terminal choices

Warp is your daily terminal (Hyper T). It provides command/option/path completions and history-based autosuggestions, so the retired Fig hooks are unnecessary. Warp documentation.

Ghostty is the optional alternative when you want a native terminal with tabs and splits. Keep your usual shell commands; no need to adopt Schnitz’s tmux shortcuts. Ghostty documentation.

Herdr is worth evaluating for multiple agent sessions: its focus is persistent workspaces and status across agent terminals. It is not part of this setup. Herdr.

In Warp, use ji project for an interactive directory picker: zoxide’s Space+Tab completion is not supported there. Both j and z work. Zoxide documentation.

Explore these when you want to. VS Code stays the default, and your existing ~/.config/nvim is left alone.

Try Schnitz’s Neovim

./setup plan --profile vim
./setup link --profile vim
./bin/schnizvim

If the plan reports an existing target, use --replace only after reviewing it. The first launch downloads plugins via lazy.nvim; language tools may require additional installation or accounts.

Press i to insert, Escape for normal mode, then :w to save, :q to quit, or :q! to abandon unsaved changes.

./setup link --profile tmux
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
tmux

Clone TPM only if that directory does not already exist. Inside tmux press ⌃ S, then ⇧ I to install plugins. This profile uses Control-S as its prefix.

Manage this setup

For a new Mac, copy this working checkout to a permanent folder, then run ./setup install. Preview with ./setup install --dry-run. Core, daily apps and the full extras list are included; --minimal skips extras. Existing VS Code and Warp files are preserved. The script saves a log and a checklist for account logins, keys and macOS permissions. Run ./setup doctor to review remaining gaps. Read docs/NEW-MAC.md and docs/MACHINE-AUDIT.md for details.

The repository is the source of truth. Change a file here, then preview or apply the part you need.

./setup plan                   # inspect the core links
./setup link --replace         # back up conflicts and link
./setup status                 # inspect link status
./setup packages               # report missing core packages
./setup packages core --apply  # install missing core packages
./setup shell                  # install missing shell plugins
./setup guide                  # open this local page

Link backups go to ~/.local/state/dotfiles/backups/. Each run prints an exact ./setup restore .../manifest.json command. Restore refuses to overwrite files you changed after linking.

Raycast on a new Mac

  1. Install Raycast. Restore Raycast with Cloud Sync or a fresh settings export; the historical export is kept privately.
  2. In Raycast Settings → Keyboard, set Hyper Key to Right Option and enable Include Shift.
  3. Register this repo’s raycast/scripts/quick open and raycast/scripts/custom folders in Raycast Script Commands. Build raycast/my-stuff separately if you use that extension.
  4. Set the launcher to ⌥ Space and check every shortcut in the table against the restored settings.
  5. Grant Accessibility permissions in macOS when the apps request them. Reconnect extension accounts inside Raycast.

What is deliberately separate

Package installation, Mac preferences, keyboard mappings, Node tools, and optional editor setup each have their own command. Running ./setup alone only shows help. No setup step resets Raycast, installs a different window manager, removes existing packages, or runs your old destructive installer.

Your original ~/dotfiles remains in place. Its keyboard instructions now describe Raycast native Hyper; both repos and your live shell use zoxide-backed j, with Fig/iTerm startup hooks removed. Open a new Warp tab to use the updated shell. The local archive preserves authored source files; dependency folders, editor history, session databases and Git metadata were excluded. Secrets and old Raycast exports stay out of version control.

Read README.md and docs/MIGRATION.md for the complete migration decisions. To update this page after editing the reviewed data, run python3 guide/build.py.
